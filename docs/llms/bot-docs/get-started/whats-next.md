# What's next?

You're ready to start building. Your dev setup is done, your Root account is active, and you've seen how Root code is organized.

Here are a few options for what to do next:

* **Follow a tutorial**: Get hands-on by working through the [tutorials](../tutorials/index.md).
* **Plan your App**: Use the [design guidelines](../design/index.md) to sketch out your code.
* **Explore a sample**: Check out a working [sample](https://github.com/RootPlatform/RootSdk.Samples) and learn from working code.
* **Join the community**: Connect with other developers in the [Root Developers](https://rootapp.gg/developer) community.
