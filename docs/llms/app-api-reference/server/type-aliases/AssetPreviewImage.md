> **AssetPreviewImage** = `object`

A thumbnail image within an `AssetPreview`.

## Properties

### height

> **height**: `number`

The height of the thumbnail in pixels.

### url

> **url**: `string`

The URL to download the thumbnail.

### width

> **width**: `number`

The width of the thumbnail in pixels.
