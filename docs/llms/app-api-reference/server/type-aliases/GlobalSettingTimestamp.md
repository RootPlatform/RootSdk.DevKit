> **GlobalSettingTimestamp** = `Date` | `undefined`

The value of a `timestamp` setting: `Date | undefined`. Returns a JavaScript `Date` object representing the timestamp selected by the community admin, or `undefined` if no value has been set.

> **Note:** This setting type is not yet available on the platform.
