A community member's current online status.

## Enumeration Members

### Active

> **Active**: `16`

The member is connected and actively using the community.

### Disconnected

> **Disconnected**: `1`

The member is offline (no devices connected to the community).

### Inactive

> **Inactive**: `4`

The member is connected but idle.

### Unspecified

> **Unspecified**: `0`

Status is unknown.
