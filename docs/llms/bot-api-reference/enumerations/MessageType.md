Enum indicating the type of message.

## Enumeration Members

### System

> **System**: `2`

A system-generated message (e.g., join notifications, channel updates).

### Unspecified

> **Unspecified**: `0`

Reserved default value. Do not use in application code.

### UserMessage

> **UserMessage**: `1`

A message created by a user.
