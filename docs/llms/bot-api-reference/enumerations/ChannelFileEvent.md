Enum providing string constants for file event names. Use these values when subscribing to events on `ChannelFileClient`.

## Enumeration Members

### ChannelFileCreated

> **ChannelFileCreated**: `"channelFile.created"`

Emitted when a file is created.

### ChannelFileDeleted

> **ChannelFileDeleted**: `"channelFile.deleted"`

Emitted when a file is deleted.

### ChannelFileEdited

> **ChannelFileEdited**: `"channelFile.edited"`

Emitted when a file is renamed.

### ChannelFileMoved

> **ChannelFileMoved**: `"channelFile.moved"`

Emitted when a file is moved to a different directory.
