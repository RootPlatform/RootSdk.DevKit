> **GlobalSettingColor** = `string` | `undefined`

The value of a `color` setting: `string | undefined`. Returns the hex color code selected by the community admin (e.g., `#ff0000`), or `undefined` if no value has been set.

> **Note:** This setting type is not yet available on the platform.
