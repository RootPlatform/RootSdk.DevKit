> **GlobalSettingChannelGroup** = [`ChannelGroupGuid`](ChannelGroupGuid.md)[]

The value of a `channelGroup` setting: `ChannelGroupGuid[]`. Returns an array of channel group IDs selected by the community admin.

> **Note:** This setting type is not yet available on the platform.
