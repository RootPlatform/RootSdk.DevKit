> **ChannelGroupDeleteRequest** = `object`

Request to delete a channel group. Deleting a channel group also deletes all channels within it.

## Properties

### id

> **id**: [`ChannelGroupGuid`](ChannelGroupGuid.md)

The ID of the channel group to delete. Required.
