Enum providing string constants for community emoji event names. Use these values when subscribing to events on `CommunityEmojiClient`.

## Enumeration Members

### CommunityEmojiCreated

> **CommunityEmojiCreated**: `"communityEmoji.created"`

Emitted when a new custom emoji is added to the community.

### CommunityEmojiDeleted

> **CommunityEmojiDeleted**: `"communityEmoji.deleted"`

Emitted when a custom emoji is removed from the community.
